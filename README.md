## Як подаються роботи

Лабораторні 1–4 — один проєкт, що розвивається: кожна наступна папка починається з копії
попередньої (коміт `Lab N: start from Lab N−1 project`).

Починаючи з лабораторної № 3, кожна робота подається окремим **pull request** (гілки `lab3`, `lab4`, `lab5`) —
рецензенти залишають коментарі у вкладці *Files changed* до конкретних рядків, а історію кроків
видно у вкладці *Commits*. Для лабораторної № 3 це коміти з префіксами `red:`, `green:`, `refactor:`.

## Запуск

```bash
cd lab3            # або інша папка
npm ci
npm test           # Vitest
npm run coverage   # покриття (лаби 1–4)
```

Для лабораторної № 5: `npm start` запускає сервіс на `http://127.0.0.1:3000`,
`npm run newman` — колекцію `postman/orders.postman_collection.json`.
