# Лабораторна робота № 1 — Автоматизація тестування

**Тема:** Розгортання середовища автоматизації тестування. Структура проєкту та перший автоматизований тест.

**Виконавець:** Бурдай Василь Миколайович, 4 курс, спеціальність «Інженерія програмного забезпечення»
**Варіант:** 7 — перетворення оцінки за стобальною шкалою на оцінку ЄКТС; відхилення значень поза діапазоном.

## Структура

```
qa-automation/
├── src/
│   ├── temperature.ts   # показовий приклад (°C → °F)
│   └── ects.ts          # варіант 7 (100-бальна шкала → ЄКТС)
├── tests/
│   ├── temperature.test.ts
│   └── ects.test.ts
├── .gitignore
├── .prettierrc
├── eslint.config.mjs
├── package.json
├── package-lock.json
├── tsconfig.json
├── vitest.config.ts
└── README.md
```

## Встановлення та запуск

```bash
npm ci                 # встановити залежності за package-lock.json
npm test               # одноразовий прогін тестів
npm run test:watch     # режим спостереження
npm run coverage       # прогін із покриттям (звіт у coverage/index.html)
npm run lint           # статичний аналіз
npm run format         # форматування Prettier
```

Вимоги: Node.js 20+ (перевірено на v22.22.0), npm 10+.
